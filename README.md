The worst app idea ever pitched, written for the make.fun bounty of
that name, and pitched completely straight: SnoozeCoin, an alarm that
charges real money per snooze and reinvests in louder alarms. The
funding round opens when users are awake enough to sign, which, by
design, is never. Term sheets available on request, after nine snoozes.

## Running it

`node main.ts` clears the output directory's contents and writes the
pitch to `/output/entry.txt` as plain UTF-8 text.
